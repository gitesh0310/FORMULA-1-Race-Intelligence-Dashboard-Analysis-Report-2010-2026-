Project Overview

Turning race data into insight

Formula 1 generates a rich mix of results, teams, drivers, circuits and race-status information. This project organizes those fields into visual views that help users explore performance patterns and compare results across seasons.

Championships

Compare team points and seasonal performance trends.

Driver Performance

Review points, finishing positions and podium results.

Tyre Strategy

Explore tyre-compound usage across circuit types.

Reliability

Investigate DNF records and reported causes.

Project Methodology

From data to dashboard

The workflow follows the main phases of a data-visualization project, from defining the problem to testing and documenting the final Tableau story.

1

Ideation & Problem Definition

Identify the audiences, questions and decisions that race-performance analysis should support.

2

Requirement Analysis

List the key measures, dimensions, filters and expected dashboard interactions.

3

Project Design

Plan the visualizations, dashboard layout, color hierarchy and story sequence.

4

Project Planning

Organize data preparation, worksheet creation, dashboard assembly and review tasks.

5

Project Development

Connect the dataset to Tableau, build calculated fields, create worksheets and combine them into dashboards.

6

Performance Testing

Check filter behavior, labels, tooltips, layout responsiveness and loading. Record actual test results rather than assumed timings.

7

Documentation

Document the problem statement, data fields, chart choices, dashboard design, limitations and conclusions.

8

Project Demonstration

Present the dashboard and story, explain key interactions and clarify the dataset's limitations.

Core Visualizations

KPI summary, team points trend, driver leaderboard, podiums by driver, tyre compound by circuit type, races by host country, DNF by team/cause and DNF rate by season.
